# 1️⃣2️⃣ Estrutura e Processos de Formação de Palavras

⬅️ [[11-Pontuação]] | ➡️ [[13-Sintaxe-do-Período-Simples]]

> [!important] Relevância prática
> Entender **como** as palavras se formam ajuda a decifrar o significado de palavras desconhecidas em uma prova — e a antecipar pegadinhas de derivação x composição.

## 🧠 Estrutura das palavras (morfema)

```mermaid
mindmap
  root((Morfema))
    Radical
      Parte comum a uma serie de palavras
      Casa Casamento Casarão
    Vogal Temática
      Radical + Vogal = Tema
      Cas + a
    Desinência Nominal
      Genero e numero
      Casas
    Afixos
      Prefixo antes do radical: ingrato
      Sufixo depois do radical: gratidão
```

## 🌱 Processos de Formação — Derivação

```mermaid
mindmap
  root((Derivação))
    Prefixal
      Prefixo + palavra primitiva: feliz→infeliz
    Sufixal
      Palavra primitiva + sufixo: pedra→pedreiro
    Prefixal e Sufixal
      Prefixo + palavra + sufixo: feliz→infelizmente
    Parassintética
      Prefixo e sufixo simultâneos ao radical: pobre→empobrecer
      ATENÇÃO: sem os dois juntos a palavra não existe
    Regressiva
      Redução da palavra: comprar→compra
      Geralmente vira substantivo
    Imprópria
      Muda de classe gramatical mantendo a forma
      Jantar verbo→substantivo
```

> [!danger] Pegadinha: Parassintética
> Só é parassintética quando o prefixo **e** o sufixo são indispensáveis **ao mesmo tempo** — se você remover só um deles e a palavra intermediária não existir (\*pobrecer, \*empobre), é parassintética.

## 🌳 Processos de Formação — Composição

```mermaid
mindmap
  root((Composição))
    Justaposição
      Junção sem perda de fonemas: beija-flor passatempo
    Aglutinação
      Junção com mudança/perda no radical: plano+alto→planalto
    Compostos Eruditos
      Radicais gregos ou latinos: penta+gono→pentágono
    Hibridismo
      Palavras de línguas diferentes: report inglês + agem sufixo
```

## 🆕 Outros processos

```mermaid
mindmap
  root((Outros processos))
    Neologismo
      Semântico palavra existente com novo sentido: pistolão
      Sintático combinação com novo sentido: deu a volta por cima
      Lexical palavra nova: escanear
    Abreviação
      Redução ao limite compreensivel: foto pneu
    Onomatopeia
      Reproduz sons: catapimba miar zumzum
```

> [!example] Justaposição x Aglutinação
> - Justaposição (nada se perde): *guarda + chuva → guarda-chuva*
> - Aglutinação (o radical muda/funde): *plano + alto → planalto*
