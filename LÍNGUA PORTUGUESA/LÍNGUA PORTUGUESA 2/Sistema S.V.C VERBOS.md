### Módulo 1: O Scanner do Pedágio (Objetos)

> [!success] Exercício 1 | #resposta #questão #Português #Sintaxe - Objetos _[[G7_Jurídico]]_ _[[Aula_3]]_ _[[Fixação]]_ **ENUNCIADO:** Classifique os termos usando: (A) Obj. Direto, (B) Obj. Direto Preposicionado, (C) Obj. Indireto.
> 
> > [!quote] Explicação (Auditoria da Oficina):
> > 
> > 1. Adoramos **nossas sogras**. -> Quem adora, adora alguém (VTD). Via expressa = (A) Obj. Direto.
> >     
> > 2. Eduardo Paes cumpriu **com a palavra**. -> Cumprir é VTD, mas ganhou preposição por estilo. = (B) Obj. Direto Preposicionado.
> >     
> > 3. Convidaram-**me** para uma grande festa. -> Quem convida, convida alguém (VTD). O "me" é o alvo direto. = (A) Obj. Direto.
> >     
> > 4. As mulheres desconfiam **dos homens**. -> Quem desconfia, desconfia DE alguém (VTI). = (C) Obj. Indireto.
> >     
> > 5. Sabe-se que Brutus traiu **a Nero**. -> Trair é VTD. O "a" é pedágio de estilo (nome próprio). = (B) Obj. Direto Preposicionado.
> >     
> > 6. Obedeço **aos meus superiores**. -> Quem obedece, obedece A alguém (VTI). = (C) Obj. Indireto.
> >     
> > 7. Não temas **da morte**. -> Temer é VTD. O "da" é pedágio estilístico. = (B) Obj. Direto Preposicionado.
> >     
> > 8. Não concordaram **com o projeto**. -> Quem concorda, concorda COM algo (VTI). = (C) Obj. Indireto.
> >     
> > 9. Fazer **samba** lá na Vila é um brinquedo. -> Quem faz, faz algo (VTD). = (A) Obj. Direto.
> >     
> > 10. O policial sacou **do revólver**. -> Sacar é VTD. A preposição indica a parte do todo (sentido partitivo). = (B) Obj. Direto Preposicionado.
> >     
> > 11. Amarás **a Deus** sobre todas as coisas. -> Amar é VTD. A preposição é por reverência. = (B) Obj. Direto Preposicionado.
> >     
> 
> **SUA RESPOSTA:** GABARITO: A, B, A, C, B, C, B, C, A, B, B.
>

### Módulo 2: A Batalha CN vs. AA

> [!success] Exercício 2 | #resposta #questão #Português #Sintaxe - CN x AA
> 
> _[[G7_Jurídico]]_ _[[Aula_3]]_ _[[Fixação]]_
> 
> **ENUNCIADO:** Classifique os termos em CN (Complemento Nominal) ou AA (Adjunto Adnominal):
> 
> > [!quote] Explicação (Teste do Scanner Ativo/Passivo):
> > 
> > - **a. Tinha medo da noite.** -> Medo (abstrato). A noite sofre o medo (Passivo). = **CN**.
> >     
> > - **b. Ela é digna de pena.** -> Digna (Adjetivo). Só aceita = **CN**.
> >     
> > - **c. É preciso ter respeito a todos.** -> Respeito (abstrato). Todos recebem o respeito (Passivo). = **CN**.
> >     
> > - **d. Está enorme a fila do leite.** -> Fila (Concreto). Regra de Ouro = **AA**.
> >     
> > - **e. O amor ao filho reanimava a mãe.** -> Amor (abstrato). O filho recebe o amor (Passivo). = **CN**.
> >     
> > - **f. A descoberta do rapaz deixou-o famoso.** -> Descoberta (abstrato). O rapaz descobriu algo (Ativo). = **AA**.
> >     
> > - **g. A descoberta de ouro...** -> Descoberta (abstrato). O ouro foi descoberto (Passivo). = **CN**.
> >     
> > - **h. O rapaz mora perto de casa.** -> Perto (Advérbio). Só aceita = **CN**.
> >     
> > - **i. O apoio ao amigo fê-lo feliz.** -> Apoio (abstrato). O amigo recebe apoio (Passivo). = **CN**.
> >     
> > - **j. A leitura do anúncio fez-se em voz alta.** -> Leitura (abstrato). O anúncio foi lido (Passivo). = **CN**.
> >     
> > - **k. A leitura do aluno era deficiente.** -> Leitura (abstrato). O aluno lia (Ativo). = **AA**.
> >     
> > - **l. A mesa de vidro quebrou.** -> Mesa (Concreto). Material de fábrica = **AA**.
> >     
> > - **m. O fumo é nocivo à saúde.** -> Nocivo (Adjetivo). Só aceita = **CN**.
> >     
> > - **n. Agiu favoravelmente a nós.** -> Favoravelmente (Advérbio). Só aceita = **CN**.
> >     
> > - **o. A admiração do povo pelo Ronaldinho...** -> Admiração (abstrato). Povo admira (Ativo) = **AA**. Ronaldinho é admirado (Passivo) = **CN**.
> >     
> 
> **SUA RESPOSTA:** GABARITO Aplicado.
> 
> **Conceitos:** [[Sintaxe]] | [[Adjunto Adnominal vs Complemento Nominal]].

### Módulo 3: O Certo e Errado (Pegadinhas de Prova)

Organizei a numeração que estava duplicada no PDF e adicionei a explicação mecânica de cada uma:

>[!success] Questões de Prova | #resposta #questão #Português #Sintaxe - Mista
> 
> _[[G7_Jurídico]]_ _[[Aula_3]]_ _[[Simulado]]_
> 
> **ENUNCIADOS E JULGAMENTOS:**
> 
>>[!quote] Questão 1 (Fixação pág 19): "O professor Sidney produziu um simulado..." Sidney é adjunto adnominal. **ERRADO.** "Sidney" é um Substantivo Próprio que está especificando o substantivo genérico "professor". Isso não é um acessório de característica, é uma "etiqueta de identificação". O nome dessa peça é **Aposto Especificativo**.


> 
>>[!quote] Questão 2 (Prova pág 21): "A filmagem da cena foi coordenada..." A expressão destacada (da cena) é Complemento Nominal. **CERTO.** Filmagem (Substantivo Abstrato de ação). A cena não filma nada, ela _é filmada_ (Alvo / Passivo). Logo, é Complemento Nominal.






> 
> > [!quote] Questão 3 (Prova pág 22): "João disse para Maria: o fumo lhe é prejudicial.". O vocábulo "lhe" é um objeto indireto. **ERRADO.** O fumo é prejudicial _a quem_? A ele ("lhe"). A mangueira dessa palavra está ligada ao adjetivo "prejudicial", e não a um verbo. Se completa o sentido de um adjetivo (Nome), a função é **Complemento Nominal**, não Objeto. (Essa derruba muita gente!).
> 
> > [!quote] Questão 4 (Prova pág 22): "A Polícia prendeu dois traficantes de drogas.". O termo (dois traficantes...) funciona como complemento verbal. **CERTO.** Quem prende, prende alguém. O verbo prender é VTD. O alvo ("dois traficantes") é o Objeto Direto (que é o nome técnico do complemento verbal direto).
> 
> > [!quote] Questão 5 (Prova pág 23): "A festa acabou / A luz apagou / O povo sumiu...". Em relação aos verbos destacados, pode-se afirmar que: **LETRA D (Correta).** Todos os verbos destacados são intransitivos e estão no pretérito perfeito. _Auditoria:_ Neste contexto de poema, as ações encerram-se em si mesmas. O povo sumiu e pronto. Não pede "o quê" nem "quem". São carros autônomos (Intransitivos). E indicam uma ação já concluída no passado (Pretérito Perfeito).
> 
> **SUA RESPOSTA:** Gabarito 1:E, 2:C, 3:E, 4:C, 5:D.
> 
> **Conceitos:** [[Sintaxe]] | [[Transitividade Verbal]] | [[Aposto Especificativo vs AA]].
